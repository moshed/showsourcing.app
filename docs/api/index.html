Show Sourcing API

Plain text for AI agentsOpenAPI spec

Show Sourcing has two ways for your own code and AI tools to reach your team's products and vendors:

  1. REST API (v1): plain JSON over HTTPS. Use it from any language, script or no-code tool.
  2. MCP server: for Claude, ChatGPT, Claude Code and other MCP apps. See MCP server below.

Both use the same token. Machine-readable spec: https://showsourcing.app/openapi.json. This page as plain text: https://showsourcing.app/docs/api.md.

REST API (v1)

Base URL: https://api.showsourcing.app/functions/v1/api

All routes sit under /v1. Every request and response is JSON.

Auth

The API uses the same token as the AI Connection. One token works for both.

  1. In the app (iPhone, iPad, Mac or Android), open Settings > AI Connection & API.
  2. Tap Create token. To add data, turn on "Can add products and vendors". The app shows the token once.
  3. Send it in a header on every request:
Authorization: Bearer ss_xxxxxxxx

X-API-Key: ss_xxxxxxxx also works.

A token is tied to one team. It can only see that team's data. A token is read-only unless you made it with write access. Revoke a token in the app and it stops working at once.

A token stops working when its owner leaves the team. Make a new one.

Plans

  • With a paid plan, you see everything.
  • On a free trial or with no plan, reads show only your first 10 products and first 5 vendors. The response has a plan_limit note.
  • Adding data (POST) needs a paid plan or a free trial. With no plan, POST returns 402.

Routes

RouteWhat it does
GET /v1/productsList and search products
GET /v1/products/{id}One product, with photo links
POST /v1/productsAdd a product (write token)
GET /v1/vendorsList and search vendors
GET /v1/vendors/{id}One vendor
POST /v1/vendorsAdd a vendor (write token)

There is no update or delete in v1.

List products

GET /v1/products?q=&limit=&offset=&updated_since=

ParameterMeaning
qSearch text (max 200 characters). Matches vendor, category, notes, venue and the photo description.
limitRows to return. Default 50, maximum 200.
offsetRows to skip. Default 0.
updated_sinceISO 8601 date. Only products changed at or after it. These come oldest change first, so you can page through changes.

Without updated_since, newest products come first.

Get one product

curl -H "Authorization: Bearer $SS_TOKEN" \
  "https://api.showsourcing.app/functions/v1/api/v1/products/6f1c0a52-8d54-4a4b-9a43-0d7a1f3c9e10"

It returns the same fields as the list, plus photos: up to 8 photo links (images only, no videos). The links expire after 7 days.

Add a product

POST /v1/products with a write token.

curl -X POST -H "Authorization: Bearer $SS_TOKEN" -H "Content-Type: application/json" \
  -d '{"vendor":"Shenzhen ABC","name":"LED desk lamp","category":"Lamps","fob":4.2,"currency":"USD","moq":500,"notes":"USB powered","tags":["led","desk"]}' \
  "https://api.showsourcing.app/functions/v1/api/v1/products"

It returns 201 and the new product. The product shows up on the team's phones through normal sync.

FieldTypeNotes
vendorstring, max 200Vendor name. If the team has a vendor with this name (case ignored), the product links to it. If not, a new vendor with this name is created.
vendor_idUUIDLink to an existing vendor. Use this or vendor.
namestring, max 200Product name. The app has no name field, so it is saved as the first line of the notes.
categorystring, max 100
fobnumber, 0 to 1,000,000,000FOB price per unit.
currencystring3-letter code. Default USD.
price_termstringFOB, CIF, EXW or DDP.
moqwhole numberMinimum order quantity.
container_qtywhole numberUnits per container.
specs or notesstring, max 5000Notes (the app calls this field Notes). If you send both, they are joined.
tagsarray of strings, or one comma listMax 30 tags, 50 characters each.
country_of_originarray of strings, or one comma listMax 10.
venuestring, max 200Show or place.

Send at least one of vendor, vendor_id, name, category, fob, specs, notes. Other fields return 400 unknown_field. Photos are not part of v1. Add photos in the app.

Get one vendor

GET /v1/vendors/{id} returns the same fields, plus photos: up to 4 photo links (business card photos).

Add a vendor

POST /v1/vendors with a write token.

curl -X POST -H "Authorization: Bearer $SS_TOKEN" -H "Content-Type: application/json" \
  -d '{"name":"Shenzhen ABC","contact":"Cindy Liu","email":"cindy@abc.example","phone":"+86 755 0000 0000","website":"https://abc.example","address":{"street":"12 Example Road","city":"Shenzhen","country":"China"}}' \
  "https://api.showsourcing.app/functions/v1/api/v1/vendors"

It returns 201 and the new vendor.

contact / contactsname string, or {name, title}; or an array of themMax 20.
email / emailsstring, or array of stringsMust look like an email address. Max 20.
phone / phonesnumber string, or {number, type}; or an arraytype is mobile, office, fax or other. A plain string gets office. Max 20.

If the team already has a vendor with the same name (case ignored), the API returns 409 already_exists with the existing id. Other fields return 400 unknown_field.

Errors

Every error has this shape:

{ "error": { "code": "invalid_token", "message": "This token is not valid. It may be revoked." } }
StatusCodeWhen
400invalid_request, invalid_json, invalid_id, unknown_field, vendor_not_found, vendor_not_linkedBad input. The message says which field.
401missing_token, invalid_tokenNo token, an unknown token, or a revoked token.
402plan_requiredPOST with no plan and no trial.
403read_only_tokenPOST with a token that has no write access.
403no_team, team_changedThe token has no team, or its owner left the team.
404not_foundNo such route, or no such row in your team.
405method_not_allowedFor example DELETE. The Allow header lists what works.
409already_existsA vendor with this name exists.
429rate_limitedToo many requests. The Retry-After header gives seconds.
500internal_errorOur side. Try again.

Limits

  • 120 requests per minute per token. Every response has X-RateLimit-Limit and X-RateLimit-Remaining.
  • Request body: 100 KB.
  • Photo links expire after 7 days. Ask again for new links.

MCP server

The MCP server lets an AI app search your catalog in plain words ("which vendors had LED desk lamps under $5?"). You use your own AI account. We never see your AI key.

  • Server URL: https://api.showsourcing.app/functions/v1/mcp
  • Transport: Streamable HTTP (not STDIO).
  • Auth: the same token, as Authorization: Bearer ss_xxxxxxxx. Apps that cannot send headers can put it in the URL instead: https://api.showsourcing.app/functions/v1/mcp?key=ss_xxxxxxxx (treat that URL like a password).
  • Read only. The MCP server never adds, edits or deletes.

Tools

ToolWhat it does
search_productsSearch the team's products by vendor, category, specs, tags or photo description. Returns id, vendor, category, FOB price, MOQ and photo count.
get_productThe full record of one product, including LDP (landed duty paid, USD) and photos.
show_productsShows up to 12 products as one photo grid (photo, vendor, price, MOQ).
vendor_for_emailFinds the vendor an email address belongs to (exact address first, then the company domain) and lists its products.
list_vendorsThe team's vendors, with how many products each has. Optional name filter.

Connect

  • Claude: Settings > Connectors > Add custom connector. Name: Show Sourcing. URL: the server URL with ?key=<your token>. Leave the OAuth fields empty.
  • ChatGPT (Mac app): Settings > Apps > Connect to a custom MCP. Type: Streamable HTTP. URL: the server URL. Under Headers add Authorization = Bearer <your token>.
  • Claude Code:
claude mcp add --transport http show-sourcing https://api.showsourcing.app/functions/v1/mcp --header "Authorization: Bearer $SS_TOKEN"

The app shows these steps with your real token filled in, under Settings > AI Connection & API.
